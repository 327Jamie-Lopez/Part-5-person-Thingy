## Notebook outputs
When the notebook is run in Colab, it creates:
- `telco_training_data.csv`
- `telco_testing_data.csv`
- `telco_churn_cleaned_training.csv`
- `telco_churn_final_processed_training.csv`

The notebook keeps the testing data untouched and performs EDA/preprocessing on the training data only.
